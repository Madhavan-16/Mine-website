MiNe static assets — self-contained deploy layout
=================================================

Everything the website needs for images, fonts, and UI bundles lives under static/.
Copy the whole MiNe folder (including static/, templates/, mine/, config/, mine.db if present) to deploy.

Directory map
-------------
static/css/          Stylesheets (fonts.css loads self-hosted Inter)
static/fonts/inter/  Inter woff2 — no Google Fonts CDN required
static/img/          Raster infographics, logos, journey art
  domain/            Open-pit copper domain knowledge infographics (6 PNGs)
  hero-motifs/       Landing bento modal images (5 topics)
  journey/           Freeport–Hexaware journey infographics (partnership milestones archive + current)
  leadership/        Executive portrait thumbnails (12 PNGs)
static/js/           Application scripts and motion bundles
static/vendor/       Vendored AOS + GSAP (no CDN)
config/hero_showcase.json  Landing hero YouTube embeds (@freeportfcx)

Landing hero videos
-------------------
Hero showcase uses YouTube thumbnails; play opens an in-page lightbox with embed + audio (config/hero_showcase.json).

Refresh bundled assets
----------------------
  python scripts/bundle_deploy_assets.py    # re-download Inter fonts if needed
  python scripts/sync_static_site_assets.py # mirror img/fonts into static_site/
  python scripts/prepare_deploy.py          # bundle + sync + verify (recommended before deploy)

Verify before deploy
--------------------
  python scripts/verify_deploy_assets.py

Runtime data (not wiped by Azure git deploy)
-------------------------------------------
  Local:     mine.db + uploads/ under the project folder
  Azure:     /home/data/mine/mine.db + /home/data/mine/uploads (persistent)
             Run scripts/azure_fix_portal.sh once after this change.
  Merge:     python tools/merge_catalog_into.py --help
             (publish local-only catalogue rows into a DB without deleting existing rows)

Runtime data (not in static/)
-----------------------------
  mine.db              SQLite database (created on first run if missing)
  uploads/             User-uploaded content files
  logs/                Mail outbox when MAIL_DUMMY=1

External links (optional, not required for core UI)
---------------------------------------------------
  Landing hero YouTube links (requires internet for thumbnails/watch)
  Footer links to hexaware.com and fcx.com
  Office Online embed for PPT preview (optional feature)
  Microsoft Graph mail (optional admin feature)
